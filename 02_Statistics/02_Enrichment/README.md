# 02_Enrichment

Runs every pathway test once, so the comparisons only slice the results.

| | |
|---|---|
| Reads | `01_Processing/04_Gene_Sets/c_data/gene_sets.rds`, `02_Statistics/01_Fit/c_data/fit.rds`, `02_Statistics/01_Fit/c_data/study_full/`, `02_Statistics/01_Fit/c_data/study_mito/` |
| Writes | `c_data/02_enrichment.xlsx`, `c_data/enrichment.rds` (read by `03_Comparisons` and `04_Figures/`), `b_reports/02_enrichment.pdf` |
| Run | `Rscript 02_Statistics/02_Enrichment/a_script/02_enrichment.R` |

- **Contrasts:** `enrichVolcano::run_enrichment(tests = "fgsea")` on the moderated t of each comparison's contrast, one contrast at a time, seed 20260910. GO:BP, Reactome, Hallmark and KEGG LEGACY in the full proteome, MitoCarta in the mitochondrial universe; BH within contrast and collection. Each row carries the same set's singscore contrast from `02_Statistics/01_Fit` (log2 FC, p, FDR, r with group), which is tested across mice.
- **Redundancy:** `enrichVolcano::dedup_terms(method = "collapse_pathways")`, which runs `fgsea::collapsePathways` within each contrast and collection: an FDR-level term is `redundant` when it is no longer enriched once a stronger term's genes are conditioned on, and `kept` otherwise; `merged_into` names its parent. Chosen over EnrichmentMap, set cover and affinity propagation in a trial; figures use the flag to pick display terms; nothing is dropped.
- **Other tests:** GO Slim compartments; the literature and ROS sets as one list, BH across it; fgsea on each protein's phenotype-association t per sex and association model (co-movement, not a PAS effect), beside the singscore association; cross-sex signatures (each sex's p ≤ 0.05 up and down proteins tested in the other sex's PAS contrast by `limma::fry`, across mice, with the fit's design and limpa's weights); ORA (`fgsea::fora`) of each response pattern of the PAS F-test proteins against every detected gene; STRING v12 connectivity of the Π and FDR protein lists.
- **Result (p ≤ 0.05 / FDR ≤ 0.05):** female GO:BP 95 / 10, Reactome 24 / 0, Hallmark 2 / 1, KEGG 6 / 0, MitoCarta 11 / 2; male GO:BP 161 / 35, Reactome 16 / 0, Hallmark 6 / 1, KEGG 7 / 5, MitoCarta 6 / 0; treatment × sex GO:BP 93 / 20, Reactome 19 / 6, Hallmark 3 / 3, KEGG 8 / 2, MitoCarta 12 / 11. collapsePathways keeps 8 of 13 FDR-level terms in females, 12 of 41 in males and 22 of 42 for the interaction. No cross-sex signature carries into the other sex by fry (p 0.17 to 0.81), although 50 to 74% of each list moves the same way. Pattern ORA: proteins up in females and down in males are enriched for muscle contraction (Reactome striated muscle contraction FDR 6e-6, muscle contraction 0.001; Hallmark myogenesis 0.03); no other pattern has a term at FDR ≤ 0.05.
- **Basis:** fgsea (Korotkevich et al.) through enrichVolcano for the main tests; the compartment and literature lists call `fgsea::fgsea(nPermSimple = 10000)` directly, as fgsea advises when a set's gene-level statistics are unbalanced, because enrichVolcano keeps the default and such a set would lose its p-value; Korotkevich et al. for `collapsePathways`; Wu & Smyth 2012 for fry, and on why gene-permutation tests run optimistic when genes are correlated, which is why the cross-sex signatures moved from fgsea to fry: fgsea had put three of them at p ≤ 0.006. NES rebuilt from the GSEA definition with 20,000 random sets matches within 0.035.
- **Note:** The fgsea test permutes genes, so its FDR runs optimistic against the singscore test; several FDR-level MitoCarta terms have singscore p > 0.2. The STRING lists are descriptive: subunits of one complex vary together.
