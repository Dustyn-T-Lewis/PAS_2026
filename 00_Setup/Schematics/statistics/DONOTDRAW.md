# Do not draw

- icons, pictograms, mice, people, organs, tubes, instruments, logos or decorations
- charts, plots, ROC curves, PCA plots, networks, data points or mock results
- any number that is not written in the spec
- arrows or lines between the seven step cards
- p-values, or any result other than the two R² values
- any contrast label twice
- arrows meaning up- or down-regulation
- step names, folder names or file names that are not in the spec
- colour names or colour codes written as text
- an arrow that starts or ends at an individual step card (arrows join only the large panel's outer edge to 01_Processing, 03_Comparisons and 04_Figures)
